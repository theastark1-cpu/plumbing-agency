## Rubric Framework

### Layer 0 — Binary Gates (all must PASS)

| Gate | Question |
|------|----------|
| G1 — Physical/walk-in | Is it a brick-and-mortar or location-based service (non-remote)? |
| G2 — Transaction value | Does the average transaction clear the revenue bar for retainer affordability? |
| G3 — Proven demand | Is there public evidence of agencies succeeding in this vertical? |
| G4 — Owner reachability | Are >30% of owners directly reachable (not franchise/PE-gated)? |

### Layer 1 — Scored Dimensions

| Dim | Weight | What it measures |
|-----|--------|-----------------|
| D1 — Moat & Founder Edge | 34% | How uniquely suited is the founder's tech stack to this vertical? Can the build become the system of record? |
| D2 — Unit Economics | 28% | Margins, recurring potential, seasonality, retainer affordability |
| D3 — Competitive Headroom | 22% | Advertiser presence, CPC band, whitespace, category ownership |
| D4 — Replication / Velocity | 16% | Operator count, trade groups, demo-ability, proof travel speed |

### Anti-Vanity Cap

D1 is capped at: `avg(D2, D3, D4)` — prevents overrating the founder's edge relative to market fundamentals.

### Time to First Client

```
Base 6 weeks
− [penalty/reduction based on G4, D3, D4]
```
